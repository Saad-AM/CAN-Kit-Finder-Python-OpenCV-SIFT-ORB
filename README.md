# 🦁 CAN Kit-Finder (Computer Vision)

### 📝 Description
An intelligent tool designed for the Africa Cup of Nations (CAN) 2025. This application uses **Computer Vision** to identify official football kits based on federation logos.

It solves a real problem: helping fans and tourists distinguish official merchandise from counterfeits or outdated versions.

### 🛠️ Tech Stack
* **Language:** Python 3.x
* **Library:** OpenCV (cv2)
* **Algorithms:** SIFT / ORB (Feature Matching)
* **Data:** Custom dataset of logos and jersey images.

### 🚀 Key Features
* [x] Federation Logo Recognition
* [x] Image retrieval from a local database (CBIR)
* [x] Feature matching visualization
